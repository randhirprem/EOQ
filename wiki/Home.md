# Stockwise project wiki

Stockwise is a browser-based inventory planning demo with economic order quantity
(EOQ) calculations, monthly demand forecasts and downloadable PDF reports.

- [Getting started](Getting-Started.md)
- [Planning and forecasting](Planning-and-Forecasting.md)
- [Accounts and privacy](Accounts-and-Privacy.md)
- [License and contact](License.md)
- [Project README and detailed guides](../README.md)
- [Development checks](../tests/README.md)

These Markdown pages form the local project wiki. They have not been published
to a hosted wiki. All application code is in `index.html`; the deployment guide
describes future production work, not an implemented backend.
