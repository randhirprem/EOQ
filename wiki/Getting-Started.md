# Getting started

From the project folder, run:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Open <http://localhost:8080> in a modern browser. Internet access is required for
the CDN libraries and statistical runtime. Account features require localhost or
HTTPS. This server is for local preview.

Create a demo account. The first account in that browser's site storage becomes
an administrator; later self-registered accounts become members. Use a password
created only for this demo. See [Accounts and privacy](Accounts-and-Privacy.md).

For a quick forecast demonstration, select **Try sample data**, which supplies
60 fictional months. The downloadable templates contain only 12 months and
demonstrate the upload format.

If loading fails, check network access to the CDNs. First-time statistical engine
loading can take a minute. Analysis can be cancelled and is limited to two minutes.
